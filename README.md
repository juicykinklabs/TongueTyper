# TongueTyper

A reinvented talking-gag platform with WiFi control, USB output, accelerometer, speaker, and haptic feedback.

## ⚠️ Pre-release
This repo is still missing a lot of documentation, and there are no releases at this time.
Feel free to take a look around though.

We're considering swapping to [this](https://a.co/d/01ACvRYG) module that combines the ESP32, display, and accelerometer, and has a BMS. It would still require a PCB for SD, audio, and the buttons/GPIO expander.

## Directory

 - GWR-firmware: ESP32-S3 firmware (platformio, arduinoespressif32)
 - PCB: printed circuit board design files (KiCAD)
 - SD-Media: SD Card files and helper scripts
    - Additional emojis may be found: https://www.emojiall.com/en/image-emoji-platform/apple/hd
 - TT-Models: 3D printable and silicone parts
